<Analogy>

A concert: at the **ticket counter** you show your ID once (username and password) and get a **wristband** (access token). At every gate after that, guards only look at the wristband; they do not ask for your ID again. When the wristband expires, you go back to the counter.

</Analogy>

## Simple explanation

The flow:

```text
1. POST /token   form: username=asha&password=s3cretpass
2. server checks the password hash → returns {"access_token": "eyJ...", "token_type": "bearer"}
3. GET /me       header: Authorization: Bearer eyJ...
4. get_current_user reads + verifies the token → the endpoint receives the user
```

The FastAPI pieces:

| Piece | Role |
| --- | --- |
| `OAuth2PasswordRequestForm` | reads `username` and `password` from **form data** (needs `python-multipart`) |
| `OAuth2PasswordBearer(tokenUrl="token")` | a dependency that extracts the token from `Authorization: Bearer ...`; returns 401 if missing; adds the **Authorize** button to `/docs` |
| `get_current_user` | your dependency: verify the token (JWT, next topic), load the user, raise 401 if invalid |
| `Depends(get_current_user)` | protects any route or router |

**Passwords: store only a hash**

```python
from pwdlib import PasswordHash        # pip install "pwdlib[argon2]"  (passlib with bcrypt also common)

password_hash = PasswordHash.recommended()     # Argon2
hashed = password_hash.hash("s3cretpass")      # store this
password_hash.verify("s3cretpass", hashed)     # True
```

Hashing is one-way and slow on purpose (bcrypt, Argon2), with a random salt so equal passwords get different hashes. Never store plain text, never use MD5/SHA-256 alone.

**Authorization** (what the user may do) is a second dependency on top: `require_admin(user = Depends(get_current_user))` raises 403 for the wrong role. Scopes (`Security(..., scopes=["orders:write"])`) give finer control.

Other options: API keys in a header (`APIKeyHeader`) for machine clients, HTTP-only cookies for browser sessions, or a managed identity provider (Amazon **Cognito**, Auth0, Keycloak) issuing the tokens.

## Code example

```python
from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from pwdlib import PasswordHash

password_hash = PasswordHash.recommended()
USERS = {"asha": {"username": "asha", "hashed_password": password_hash.hash("s3cretpass"), "role": "customer"}}

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

@app.post("/token")
def login(form: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = USERS.get(form.username)
    if not user or not password_hash.verify(form.password, user["hashed_password"]):
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Incorrect username or password",
                            headers={"WWW-Authenticate": "Bearer"})
    return {"access_token": create_access_token(user["username"]), "token_type": "bearer"}   # see JWT topic

def get_current_user(token: Annotated[str, Depends(oauth2_scheme)]):
    username = decode_token(token)            # verify signature + expiry (JWT topic)
    user = USERS.get(username)
    if user is None:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Could not validate credentials",
                            headers={"WWW-Authenticate": "Bearer"})
    return user

@app.get("/me")
def me(user: Annotated[dict, Depends(get_current_user)]):
    return {"username": user["username"], "role": user["role"]}
```

```output
POST /token  username=asha password=wrong       -> 401 {"detail": "Incorrect username or password"}  WWW-Authenticate: Bearer
POST /token  username=asha password=s3cretpass  -> 200 {"access_token": "eyJhbGciOiJIUzI1NiIs...", "token_type": "bearer"}
GET  /me     (no header)                        -> 401 {"detail": "Not authenticated"}
GET  /me     Authorization: Bearer eyJhbGci...  -> 200 {"username": "asha", "role": "customer"}
stored hash: $argon2id$v=19$m=65536,t=3,p=4...
```

<Mistakes>

<Mistake title="Storing passwords in plain text or with a fast hash">

<Wrong>

```python
user.password = form.password                     # a database leak exposes every password
user.password = hashlib.sha256(pw.encode()).hexdigest()   # fast hash: cracked by GPUs
```

</Wrong>

<Right>

```python
user.hashed_password = password_hash.hash(form.password)  # Argon2 / bcrypt, salted, slow
```

</Right>

</Mistake>

<Mistake title="Different error messages that leak which part was wrong">

if not user: raise HTTPException(404, "User does not exist")

</Wrong>

<InterviewQA>

<QA q="How do you implement authentication in FastAPI?">

A /token endpoint takes credentials via OAuth2PasswordRequestForm, verifies the password against a stored bcrypt or Argon2 hash and returns a signed access token (usually a JWT). OAuth2PasswordBearer extracts the bearer token on protected routes, and a get_current_user dependency verifies it and loads the user, raising 401 otherwise; role checks are separate dependencies returning 403.

</QA>

<QA q="How should passwords be stored?">

Only as salted, slow, adaptive hashes such as Argon2id or bcrypt (via pwdlib or passlib), never in plain text or with fast hashes like MD5 or plain SHA-256. Login verifies by hashing the given password with the stored salt and parameters.

</QA>

<QA q="What is the difference between authentication and authorization?">

Authentication establishes who the user is (credentials, token). Authorization decides what that user may do (roles, scopes, ownership checks). In FastAPI, get_current_user handles the first and returns 401 on failure; permission dependencies handle the second and return 403.

</QA>

<CheatSheet>

| Need | Code |
| --- | --- |
| Login form | `form: Annotated[OAuth2PasswordRequestForm, Depends()]` (+ python-multipart) |
| Token from header | `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")` |
| Current user | `def get_current_user(token = Depends(oauth2_scheme)): ...` |
| Protect | `user = Depends(get_current_user)` or router `dependencies=[...]` |
| Hash | `PasswordHash.recommended().hash(pw)` · `.verify(pw, hashed)` |
| 401 header | `headers={"WWW-Authenticate": "Bearer"}` |
| Roles | `require_admin(user = Depends(get_current_user))` → 403 |

</CheatSheet>
