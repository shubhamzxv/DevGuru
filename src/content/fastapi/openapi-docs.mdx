## Simple explanation

Without writing any docs you get:

| URL | What |
| --- | --- |
| `/docs` | **Swagger UI**: try every endpoint in the browser, with an Authorize button for tokens |
| `/redoc` | **ReDoc**: clean read-only reference |
| `/openapi.json` | the machine-readable **OpenAPI 3** schema |

Everything comes from your code: paths, methods, parameters with their rules, Pydantic body and response models, status codes, security schemes.

Make it better:

```python
app = FastAPI(
    title="Shop API",
    version="1.4.0",
    description="Orders, products and customers for the shop.",
)

@app.post(
    "/orders",
    status_code=201,
    tags=["orders"],
    summary="Place an order",
    response_model=OrderOut,
    responses={409: {"description": "Product out of stock"}},
)
def create_order(order: OrderIn):
    """Creates an order for the current user.

    - **quantity** must be 1 to 10
    """
```

- `tags` group endpoints; the docstring becomes the description (Markdown works)
- `Field(description=..., examples=[...])` and `model_config = {"json_schema_extra": {"examples": [...]}}` give sample bodies
- `deprecated=True` marks old endpoints; `include_in_schema=False` hides internal ones
- `openapi_tags=[{"name": "orders", "description": "..."}]` describes the groups

Uses of the schema beyond reading:

- **Generate clients**: `openapi-typescript`, OpenAPI Generator → typed TypeScript/Java/Swift clients for React and mobile apps
- **Contract tests** and mocking (Prism, Schemathesis)
- Import into **Postman** or API gateways (AWS API Gateway can import OpenAPI)

In production you may disable or protect the docs: `FastAPI(docs_url=None, redoc_url=None)` or serve them only on an internal network.

## Code example

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI(title="Shop API", version="1.4.0")

class OrderIn(BaseModel):
    product_id: int = Field(description="ID from GET /products", examples=[7])
    quantity: int = Field(default=1, ge=1, le=10, examples=[2])

@app.post("/orders", status_code=201, tags=["orders"], summary="Place an order",
          responses={409: {"description": "Product out of stock"}})
def create_order(order: OrderIn):
    """Creates an order for the logged-in customer."""
    return {"id": 1}

schema = app.openapi()
op = schema["paths"]["/orders"]["post"]
print(schema["info"])
print(op["summary"], op["tags"], list(op["responses"]))
print(schema["components"]["schemas"]["OrderIn"]["properties"]["quantity"])
```

```output
{'title': 'Shop API', 'version': '1.4.0'}
Place an order ['orders'] ['201', '409', '422']
{'type': 'integer', 'maximum': 10, 'minimum': 1, 'examples': [2], 'title': 'Quantity', 'default': 1}
```

The 422 response was added automatically because the endpoint validates input.

<Mistakes>

<Mistake title="Returning dicts with no response model">

<Wrong>

```python
@app.get("/orders/{id}")
def get_order(id: int):
    return {...}                 # docs show "Successful Response: string" — frontend has to guess
```

</Wrong>

<Right>

```python
@app.get("/orders/{id}", response_model=OrderOut)
def get_order(id: int): ...
```

</Right>

</Mistake>

<Mistake title="Public docs exposing internal endpoints">

<Wrong>

```text
/docs on the public production URL lists /admin/reindex and /internal/debug.
```

</Wrong>

<Right>

```python
@app.post("/admin/reindex", include_in_schema=False)
# or FastAPI(docs_url=None, redoc_url=None) in production, docs only internally
```

</Right>

<QA q="What is OpenAPI and how does FastAPI use it?">

OpenAPI is a standard, language-agnostic JSON/YAML description of an HTTP API: paths, operations, parameters, request and response schemas, and security. FastAPI generates it automatically from routes, type hints and Pydantic models at /openapi.json and renders interactive documentation with Swagger UI (/docs) and ReDoc (/redoc).

</QA>

<QA q="How can a frontend team use the OpenAPI schema?">

To read and try the API in Swagger UI, generate typed clients (for example openapi-typescript or OpenAPI Generator), mock the backend while it is being built, and run contract tests, so frontend and backend stay in sync.

</QA>

<CheatSheet>

| Need | Code |
| --- | --- |
| App info | `FastAPI(title=..., version=..., description=...)` |
| Group | `tags=["orders"]` |
| Short name | `summary="Place an order"` |
| Long text | docstring (Markdown) |
| Field docs | `Field(description=..., examples=[...])` |
| Extra responses | `responses={409: {"description": "..."}}` |
| Hide / deprecate | `include_in_schema=False` · `deprecated=True` |
| Turn off docs | `FastAPI(docs_url=None, redoc_url=None)` |

URLs: `/docs` · `/redoc` · `/openapi.json`

</CheatSheet>
