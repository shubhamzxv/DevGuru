<Analogy>

House addresses: "Street 5, **House 42**". The street is fixed; the house number changes. A path parameter is the house number in a URL: `/books/42`, `/users/priya`.

</Analogy>

## Simple explanation

```python
@app.get("/books/{book_id}")
def get_book(book_id: int):        # name must match {book_id}
    ...
```

- The `{book_id}` part of the path is passed to the parameter with the same name
- The **type hint** converts and validates: `/books/2` → `2` (int); `/books/abc` → **422**
- Typical types: `int`, `str`, `UUID`, `date`, and `Enum` for a fixed list

**Fixed choices with Enum**

```python
from enum import Enum

class Category(str, Enum):
    fiction = "fiction"
    tech = "tech"

@app.get("/categories/{category}")
def by_category(category: Category):
    return {"category": category, "is_tech": category is Category.tech}
```

Only `fiction` and `tech` are accepted, and the docs show a dropdown.

**Limits with Path()**

```python
from typing import Annotated
from fastapi import Path

@app.get("/orders/{order_id}")
def order(order_id: Annotated[int, Path(gt=0, le=1_000_000)]):
    ...
```

`gt`, `ge`, `lt`, `le` for numbers; `min_length`, `max_length`, `pattern` for strings.

**Order matters**: routes are checked top to bottom. Put the fixed path first:

```python
@app.get("/users/me")              # first
def me(): ...

@app.get("/users/{username}")      # after
def user(username: str): ...
```

Otherwise `/users/me` would be treated as the username "me".

**Paths containing slashes**: `/files/{file_path:path}` captures `reports/2026/nov.pdf`.

Use path parameters to **identify a resource** (`/orders/42`); use query parameters to **filter or page** (`/orders?status=paid`).

## Code example

```python
from enum import Enum
from typing import Annotated
from fastapi import FastAPI, Path

app = FastAPI()
BOOKS = {1: "Clean Code", 2: "Fluent Python"}

@app.get("/books/{book_id}")
def get_book(book_id: int):
    return {"id": book_id, "title": BOOKS.get(book_id)}

class Category(str, Enum):
    fiction = "fiction"
    tech = "tech"

@app.get("/categories/{category}")
def by_category(category: Category):
    return {"category": category, "is_tech": category is Category.tech}

@app.get("/users/me")
def me():
    return {"user": "current user"}

@app.get("/users/{username}")
def user(username: str):
    return {"user": username}

@app.get("/files/{file_path:path}")
def read_file(file_path: str):
    return {"path": file_path}

@app.get("/orders/{order_id}")
def order(order_id: Annotated[int, Path(gt=0, le=1_000_000)]):
    return {"order_id": order_id}
```


<Wrong>

<InterviewQA>

<QA q="How does FastAPI validate path parameters?">

From the type hint of the function parameter with the same name as the `{placeholder}`: it converts the string from the URL to that type and returns a 422 with details if it cannot. Extra constraints come from `Path()` (gt, le, min_length, pattern) and Enums restrict values to a fixed set.

</QA>

<QA q="When should you use a path parameter versus a query parameter?">

Path parameters identify a specific resource or a hierarchy (`/users/5/orders/9`) and are required. Query parameters are optional modifiers such as filtering, sorting, searching and pagination (`/orders?status=paid&page=2`).

</QA>

<QA q="Why does the order of routes matter?">

FastAPI (Starlette) checks routes in the order they were declared and uses the first match. A generic route like `/users/{username}` declared before `/users/me` would capture "me", so specific routes must be declared first.

</QA>
