## Simple explanation

A **data type** is the kind of a value. Python finds the type by itself from the value you write.

The basic types hold one value:

- **int**: a whole number, like `25`
- **float**: a number with a decimal point, like `99.5`
- **str**: text (a "string" of characters), like `"Asha"`
- **bool**: only `True` or `False`
- **NoneType**: the special value `None`, which means "no value"

The collection types hold many values:

- **list**: an ordered group that can change, like `["milk", "bread"]`
- **tuple**: an ordered group that cannot change, like `(28.6, 77.2)`
- **set**: a group of unique items, like `{"new", "sale"}`
- **dict**: pairs of key and value, like `{"name": "Asha"}`

Use `type()` to see the type of any value.

Some types are **mutable**, which means the value can be changed after it is made (list, set, dict). Others are **immutable**, which means it cannot (int, float, str, bool, tuple).

## Code example

```python
age = 25                         # int: whole number
price = 99.5                     # float: decimal number
name = "Asha"                    # str: text
is_member = True                 # bool: True or False
discount = None                  # NoneType: no value yet

print(type(age), type(price))
print(type(name), type(is_member), type(discount))

cart = ["milk", "bread"]         # list: ordered, can change
point = (28.6, 77.2)             # tuple: ordered, cannot change
tags = {"new", "sale"}           # set: unique items only
user = {"name": "Asha"}          # dict: key -> value
print(type(cart).__name__, type(point).__name__)
print(type(tags).__name__, type(user).__name__)

print(isinstance(age, int))      # ask: is age an int?
```

```output
<class 'int'> <class 'float'>
<class 'str'> <class 'bool'> <class 'NoneType'>
list tuple
set dict
True
```

<Mistakes>

<Mistake title="Adding text and a number">

<Wrong>

```python
print("5" + 5)   # TypeError: can only concatenate str (not "int") to str
```

</Wrong>

<Right>

```python
print(int("5") + 5)    # 10
print("5" + str(5))    # 55
```

</Right>

`"5"` is text and `5` is a number. Convert one of them so both have the same type.

</Mistake>

<Mistake title="Thinking empty curly brackets make a set">

<Wrong>

```python
items = {}
print(type(items).__name__)   # dict, not set
```

</Wrong>

<Right>

```python
items = set()
print(type(items).__name__)   # set
```

</Right>

Empty `{}` always makes a dict. Use `set()` for an empty set.

</Mistake>

<Mistake title="Treating None like zero or empty text">

<Wrong>

```python
discount = None
print(100 - discount)   # TypeError: unsupported operand type(s)
```

</Wrong>

<Right>

```python
discount = None
if discount is None:
    discount = 0
print(100 - discount)   # 100
```

</Right>

`None` means "nothing here". It is not `0` and not `""`. Check for it with `is None`.

</Mistake>

<InterviewQA>

<QA q="What are the built-in data types in Python?">

Numbers (`int`, `float`, `complex`), text (`str`), boolean (`bool`), `None`, and the collections `list`, `tuple`, `set`, `frozenset` and `dict`. There are also `bytes` and `bytearray` for binary data.

</QA>

<QA q="Which data types are mutable and which are immutable?">

**Mutable** (can change in place): `list`, `dict`, `set`, `bytearray`.

**Immutable** (cannot change): `int`, `float`, `bool`, `str`, `tuple`, `frozenset`, `bytes`.

Only immutable values can be dictionary keys or set items.

</QA>

<QA q="What is the difference between type() and isinstance()?">

`type(x)` gives the exact type of `x`. `isinstance(x, int)` answers True or False, and it also returns True for child classes. For checks in real code, prefer `isinstance()`.

```python
print(isinstance(True, int))   # True, because bool is a child of int
print(type(True) == int)       # False
```

</QA>

<QA q="What is None in Python?">

`None` is a single special object that means "no value". Its type is `NoneType`. A function without a `return` gives back `None`. Compare with `is None`, not with `==`.

</QA>
