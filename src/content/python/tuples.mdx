<Analogy>

Think of a printed train ticket. It shows the train number, the date and the seat. Once it is printed, nobody can edit those details.

A Python **tuple** is like that ticket. You can read it, but you cannot change it.

</Analogy>

## Simple explanation

A **tuple** holds many values in order, like a list. You write the values inside round brackets.

The big difference is that a tuple is **immutable**. You cannot add, remove or replace items.

Use a tuple for values that belong together and should not change, such as a point on a map or a date.

**Packing** means putting values into a tuple. **Unpacking** means taking them out into separate variables in one line.

A tuple with one item needs a comma: `(5,)`. Without the comma, `(5)` is just the number 5.

Functions use tuples to return more than one value.

## Code example

```python
point = (28.61, 77.21)             # a tuple of two numbers

print(point[0])                    # read by index, like a list
print(len(point))

lat, lon = point                   # unpacking: one name per item
print(lat, lon)

single = (5,)                      # one item needs a comma
print(type(single).__name__, type((5)).__name__)

def min_max(numbers):
    return min(numbers), max(numbers)   # returns a tuple

low, high = min_max([4, 9, 1])
print(low, high)

first, *rest = (1, 2, 3, 4)        # star collects the remaining items
print(first, rest)
```

```output
28.61
2
28.61 77.21
tuple int
1 9
1 [2, 3, 4]
```

<Mistakes>

<Mistake title="Trying to change a tuple">

<Wrong>

```python
point = (10, 20)
point[0] = 15   # TypeError: 'tuple' object does not support item assignment
```

</Wrong>

<Right>

```python
point = (10, 20)
point = (15, point[1])
print(point)   # (15, 20)
```

</Right>

You cannot edit a tuple. Make a new tuple and store it in the same name.

</Mistake>

<Mistake title="Forgetting the comma in a one-item tuple">

<Wrong>

```python
ids = (7)
print(type(ids).__name__)   # int
```

</Wrong>

<Right>

```python
ids = (7,)
print(type(ids).__name__)   # tuple
```

</Right>

The comma makes the tuple, not the brackets.

</Mistake>

<Mistake title="Unpacking into the wrong number of names">

<Wrong>

```python
a, b = (1, 2, 3)   # ValueError: too many values to unpack (expected 2)
```

</Wrong>

<Right>

```python
a, b, c = (1, 2, 3)
print(a, b, c)   # 1 2 3
```

</Right>

The number of names must match the number of items, unless you use a star: `a, *others = (1, 2, 3)`.

</Mistake>

<InterviewQA>

<QA q="What is a tuple and when would you use it?">

A tuple is an ordered, immutable collection. Use it for fixed groups of values (coordinates, a database row), for returning several values from a function, and as dictionary keys, because tuples are hashable.

</QA>

<QA q="Can a tuple contain a mutable item?">

Yes. The tuple itself cannot change which objects it holds, but a list inside it can still change.

```python
data = (1, [2, 3])
data[1].append(4)
print(data)   # (1, [2, 3, 4])
```

</QA>

<QA q="What is tuple unpacking?">

Assigning the items of a tuple to several variables in one statement. It also makes swapping easy.

```python
a, b = 1, 2
a, b = b, a
print(a, b)   # 2 1
```

</QA>

<QA q="What is a namedtuple?">

A tuple whose items also have names, from the `collections` module. It reads better than index numbers.

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p[1])   # 3 4
```

<CheatSheet>

| What you want | Code |
| --- | --- |
| Make a tuple | `t = (1, 2, 3)` |
| One item | `t = (1,)` |
| Read an item | `t[0]` |
| Unpack | `a, b, c = t` |
| Unpack the rest | `first, *rest = t` |
| Swap two values | `a, b = b, a` |
| Count a value | `t.count(1)` |
| Find a value | `t.index(2)` |
| Convert | `tuple([1, 2])`, `list(t)` |
