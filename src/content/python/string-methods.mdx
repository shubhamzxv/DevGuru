<Analogy>

Think of photo filters on your phone. You pick a photo and apply "black and white". You get a new edited photo, and the original stays as it was.

**String methods** work the same way. They never change the original text. They hand you a new string.

</Analogy>

## Simple explanation

A **method** is a function that belongs to a value. You call it with a dot: `name.upper()`.

Strings come with many methods. The most used ones are:

- `upper()`, `lower()`, `title()` change the letter case
- `strip()` removes spaces from both ends
- `replace(old, new)` swaps one piece of text for another
- `split()` cuts a string into a **list** of parts
- `join()` does the opposite: it glues a list of strings into one string
- `find()` gives the position of some text, or `-1` if it is missing
- `startswith()`, `endswith()`, `isdigit()` answer True or False

Because strings are immutable, every method returns a **new** string. Save the result if you need it.

## Code example

```python
email = "  Asha.Verma@Example.COM  "

clean = email.strip().lower()            # remove spaces, then make lower case
print(clean)

user, domain = clean.split("@")          # cut into two parts at the @
print(user, domain)

print(user.replace(".", " ").title())    # dot -> space, then Capital Letters
print(clean.endswith(".com"))            # True or False
print(clean.find("@"))                   # position of @
print(clean.count("a"))                  # how many times "a" appears

words = ["Python", "is", "fun"]
print(" ".join(words))                   # glue a list with spaces
print("2026".isdigit())                  # only digits?
```

```output
asha.verma@example.com
asha.verma example.com
Asha Verma
True
10
4
Python is fun
True
```

<Mistakes>

<Mistake title="Expecting a method to change the original string">

<Wrong>

```python
name = "asha"
name.upper()
print(name)   # asha
```

</Wrong>

<Right>

```python
name = "asha"
name = name.upper()
print(name)   # ASHA
```

</Right>

The method returns a new string. Store it, or it is lost.

</Mistake>

<Mistake title="Joining a list that has numbers">

<Wrong>

```python
marks = [80, 75, 90]
print(", ".join(marks))   # TypeError: sequence item 0: expected str instance, int found
```

</Wrong>

<Right>

```python
marks = [80, 75, 90]
print(", ".join(str(m) for m in marks))   # 80, 75, 90
```

</Right>

`join()` only works on strings. Convert each item with `str()` first.

</Mistake>

<Mistake title="Using index() when the text may be missing">

<Wrong>

```python
text = "hello"
print(text.index("z"))   # ValueError: substring not found
```

</Wrong>

<Right>

```python
text = "hello"
print(text.find("z"))   # -1
```

</Right>

`find()` returns `-1` when the text is missing. `index()` raises an error.

</Mistake>

</Mistakes>

<InterviewQA>

<QA q="What is the difference between split() and join()?">

`split()` turns one string into a list of parts. `join()` turns a list of strings into one string. They are opposites.

```python
parts = "a,b,c".split(",")
print(parts)             # ['a', 'b', 'c']
print("-".join(parts))   # a-b-c
```

</QA>

<QA q="What is the difference between find() and index()?">

Both return the position of the first match. When there is no match, `find()` returns `-1` and `index()` raises a `ValueError`.

</QA>

<QA q="How do you check if two words are anagrams?">

Anagrams have the same letters in a different order. Sort the letters of both and compare.

```python
print(sorted("listen") == sorted("silent"))   # True
```

</QA>

<QA q="How do you reverse the order of words in a sentence?">

Split into words, reverse the list, and join again.

```python
text = "I love Python"
print(" ".join(text.split()[::-1]))   # Python love I
```

</QA>

<CheatSheet>

| What you want | Code | Result |
| --- | --- | --- |
| Upper / lower case | `"Hi".upper()` | `HI` |
| Capital Letters | `"hi there".title()` | `Hi There` |
| Remove outer spaces | `" hi ".strip()` | `hi` |
| Replace text | `"a-b".replace("-", " ")` | `a b` |
| Cut into a list | `"a b".split()` | `['a', 'b']` |
| Glue a list | `"-".join(["a", "b"])` | `a-b` |
| Find position | `"hello".find("l")` | `2` |
| Count | `"hello".count("l")` | `2` |
| Starts with? | `"hello".startswith("he")` | `True` |
| Only digits? | `"42".isdigit()` | `True` |

</CheatSheet>
