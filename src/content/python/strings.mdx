<Analogy>

Think of a **mala** (a string of beads). Each bead has a fixed place: first, second, third. You can point at any bead by its position.

A Python **string** is a row of characters in the same way. Each character has a position number.

</Analogy>

## Simple explanation

A **string** (type `str`) is text. You write it inside single quotes or double quotes. Both work the same.

Each character has a position called an **index**. The index starts at **0**, not 1. A negative index counts from the end, so `-1` is the last character.

A **slice** takes a part of a string. `text[0:3]` gives the characters at positions 0, 1 and 2. The end position is not included.

Strings are **immutable**. This means you cannot change a character inside a string. You make a new string instead.

Useful basics:

- `len(text)` gives the number of characters
- `+` joins two strings, and `*` repeats a string
- `in` checks if one piece of text is inside another
- Triple quotes keep line breaks, for text on many lines

## Code example

```python
city = "New Delhi"                 # a string is text inside quotes

print(len(city))                   # number of characters, the space counts
print(city[0], city[-1])           # first and last character
print(city[0:3])                   # slice: positions 0, 1 and 2
print(city + " 110001")            # + joins two strings
print("ha" * 3)                    # * repeats a string
print("Delhi" in city)             # is this text inside?

address = """Shop 12,
MG Road"""                         # triple quotes keep the line break
print(address)
```

```output
9
N i
New
New Delhi 110001
hahaha
True
Shop 12,
MG Road
```

<Mistakes>

<Mistake title="Trying to change one character">

<Wrong>

```python
city = "delhi"
city[0] = "D"   # TypeError: 'str' object does not support item assignment
```

</Wrong>

<Right>

```python
city = "delhi"
city = "D" + city[1:]
print(city)   # Delhi
```

</Right>

Strings cannot be changed in place. Build a new string and store it in the same name.

</Mistake>

<Mistake title="Using an index that does not exist">

<Wrong>

```python
word = "abc"
print(word[5])   # IndexError: string index out of range
```

</Wrong>

<Right>

```python
word = "abc"
print(word[len(word) - 1])   # c
```

</Right>

The last valid index is `len(word) - 1`. A slice like `word[1:50]` is safe and never fails.

</Mistake>

<Mistake title="Using the same quote inside the text">

<Wrong>

```python
print('It's raining')   # SyntaxError
```

</Wrong>

<Right>

```python
print("It's raining")   # It's raining
```

</Right>

If the text has a single quote, wrap it in double quotes, or write `\'`.

</Mistake>

</Mistakes>

<InterviewQA>

<QA q="Are strings mutable in Python?">

No. Strings are **immutable**. Any operation that looks like a change, such as `upper()` or `+`, creates a new string object. This makes strings safe to use as dictionary keys.

</QA>

<QA q="How do you reverse a string?">

Use a slice with a step of -1.

```python
print("hello"[::-1])   # olleh
```

</QA>

<QA q="How do you check if a string is a palindrome?">

A palindrome reads the same both ways. Compare the string with its reverse.

```python
word = "madam"
print(word == word[::-1])   # True
```

</QA>

<QA q="What is the difference between single, double and triple quotes?">

Single and double quotes are the same; choose the one that avoids escaping. Triple quotes let the string run over many lines, and they are also used for docstrings.

</QA>
