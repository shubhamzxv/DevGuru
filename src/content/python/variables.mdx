<Analogy>

Think of the steel **dabbas** (boxes) in an Indian kitchen. Each one has a label: "Sugar", "Rice", "Dal".

The label is not the sugar. It only tells you which box to open. A Python **variable** is that label. The **value** is what is inside the box.

</Analogy>

## Simple explanation

A **variable** is a name you give to a value. You make one with the `=` sign.

This step is called **assignment**. It means "let this name point to this value". It does not mean "equal" like in maths.

Python has **dynamic typing**. This means you do not write the type (number, text) yourself. Python looks at the value and decides.

The same name can point to a new value later. The old value is simply left behind.

Rules for names:

- Use letters, digits and `_` only. Example: `total_price`
- A name cannot start with a digit. `2nd_name` is not allowed
- Names are **case sensitive**. `age` and `Age` are two different variables
- Do not use Python's own words such as `class`, `for` or `if`

## Code example

```python
name = "Asha"        # a string (text)
age = 25             # an integer (whole number)
price = 99.5         # a float (decimal number)
is_student = True    # a boolean (True or False)

print(name, age)     # print() shows values on the screen
print(type(price))   # type() tells you the kind of value

age = age + 1        # read the old value, add 1, store the result
print(age)

a, b = 10, 20        # make two variables in one line
a, b = b, a          # swap them
print(a, b)
```

```output
Asha 25
<class 'float'>
26
20 10
```

<Mistakes>

<Mistake title="Using a variable before giving it a value">

<Wrong>

```python
print(total)   # NameError: name 'total' is not defined
total = 100
```

</Wrong>

<Right>

```python
total = 100
print(total)   # 100
```

</Right>

Python reads your code from top to bottom. The name must exist before you use it.

</Mistake>

<Mistake title="Mixing up = and ==">

<Wrong>

```python
marks = 40
if marks = 40:      # SyntaxError
    print("Pass")
```

</Wrong>

<Right>

```python
marks = 40
if marks == 40:     # == compares two values
    print("Pass")
```

</Right>

One `=` stores a value. Two `==` ask the question "are these equal?".

</Mistake>

<Mistake title="Forgetting that names are case sensitive">

<Wrong>

```python
Price = 50
print(price)   # NameError: name 'price' is not defined
```

</Wrong>

<Right>

```python
price = 50
print(price)   # 50
```

</Right>

Use small letters with underscores for variable names, like `total_price`. This style is called **snake_case**.

</Mistake>

</Mistakes>

<InterviewQA>

<QA q="What is a variable in Python?">

A variable is a **name that refers to an object** in memory. It is a label, not a box that holds the value. So two names can point to the same object.

</QA>

<QA q="Is Python statically typed or dynamically typed?">

**Dynamically typed.** The type belongs to the value, not to the name, and it is checked while the program runs. So `x = 5` and later `x = "five"` is allowed.

</QA>

<QA q="What is the difference between == and is?">

`==` checks if two **values are equal**. `is` checks if two names point to the **same object in memory**.

```python
a = [1, 2]
b = [1, 2]
print(a == b)   # True  (same content)
print(a is b)   # False (two different lists)
```

Use `is` mainly for `None`, like `if x is None:`.

</QA>

<QA q="What happens when you write a = b = [] and then a.append(1)?">

Both names point to the **same list**, so `b` also shows `[1]`. To get two separate lists, write `a = []` and `b = []` on two lines.

</QA>
