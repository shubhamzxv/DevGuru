<Analogy>

A **library with signposts**: at each junction a sign says "A–M to the left, N–Z to the right". You never look in the wrong half, so finding one book among a million takes about 20 turns — as long as the library is laid out evenly (balanced). If every sign points the same way, you walk past every shelf (a chain).

</Analogy>

## Simple explanation

**BST property**: for every node, all keys in the **left** subtree < node < all keys in the **right** subtree.

```text
          8
        /   \
       3     10
      / \      \
     1   6      14
        / \     /
       4   7   13
```

| Operation | How | Time |
| --- | --- | --- |
| Search | go left if smaller, right if bigger | O(h) |
| Insert | search, attach at the empty spot | O(h) |
| Delete | leaf: remove · one child: replace with child · two children: replace with **inorder successor** (smallest in right subtree) | O(h) |
| Min / max | leftmost / rightmost node | O(h) |
| Sorted output | inorder traversal | O(n) |
| Floor / ceiling, k-th smallest | walk / inorder with a counter | O(h) / O(h + k) |

**h** = height: **O(log n)** if balanced, **O(n)** if keys were inserted in sorted order (the tree becomes a linked list). Self-balancing trees — **AVL**, **red-black** — rotate nodes to keep h = O(log n); databases use B-trees (many keys per node).

Python has no built-in BST; for sorted collections use `bisect` on a list, `heapq`, or the `sortedcontainers` library. Interviews ask you to implement and validate BSTs.

**Validate a BST**: checking only `left.val < node.val < right.val` is **wrong**; each node must respect **bounds** from all its ancestors (or check that inorder is strictly increasing).

## Code example

```python
class Node:
    def __init__(self, key):
        self.key, self.left, self.right = key, None, None

def insert(root, key):
    if root is None:
        return Node(key)
    if key < root.key:
        root.left = insert(root.left, key)
    elif key > root.key:
        root.right = insert(root.right, key)
    return root

def search(root, key):
    steps = 0
    while root:
        steps += 1
        if key == root.key:
            return True, steps
        root = root.left if key < root.key else root.right
    return False, steps

def inorder(n):
    return inorder(n.left) + [n.key] + inorder(n.right) if n else []

def delete(root, key):
    if root is None:
        return None
    if key < root.key:
        root.left = delete(root.left, key)
    elif key > root.key:
        root.right = delete(root.right, key)
    else:
        if root.left is None:
            return root.right
        if root.right is None:
            return root.left
        succ = root.right
        while succ.left:                       # smallest key in the right subtree
            succ = succ.left
        root.key = succ.key
        root.right = delete(root.right, succ.key)
    return root

def is_valid(n, lo=float("-inf"), hi=float("inf")):
    if n is None:
        return True
    return lo < n.key < hi and is_valid(n.left, lo, n.key) and is_valid(n.right, n.key, hi)

def height(n):
    return 0 if n is None else 1 + max(height(n.left), height(n.right))

root = None
for k in [8, 3, 10, 1, 6, 14, 4, 7, 13]:
    root = insert(root, k)
print("inorder:", inorder(root))
print("search 7:", search(root, 7), " search 5:", search(root, 5))
root = delete(root, 3)                          # node with two children
print("after delete 3:", inorder(root), "root.left =", root.left.key)
print("valid:", is_valid(root))

bad = Node(5); bad.left = Node(3); bad.left.right = Node(8)    # 8 is in 5's LEFT subtree
print("bad tree valid:", is_valid(bad))

chain = None
for k in range(1, 101):                         # sorted inserts
    chain = insert(chain, k)
print("height after sorted inserts:", height(chain), "| search 100 steps:", search(chain, 100)[1])
```

```output
inorder: [1, 3, 4, 6, 7, 8, 10, 13, 14]
search 7: (True, 4)  search 5: (False, 4)
after delete 3: [1, 4, 6, 7, 8, 10, 13, 14] root.left = 4
valid: True
bad tree valid: False
height after sorted inserts: 100 | search 100 steps: 100
```

def kth_smallest(root, k):
    stack, n = [], root
    while stack or n:
        while n:
            stack.append(n); n = n.left
        n = stack.pop()
        k -= 1
        if k == 0:
            return n.key
        n = n.right

<InterviewQA>

<QA q="What is a binary search tree?">

A binary tree where, for every node, keys in the left subtree are smaller and keys in the right subtree are larger. Search, insert and delete follow a single root-to-leaf path in O(h) time, and an inorder traversal lists keys in sorted order.

</QA>

<QA q="How do you validate a BST?">

Recurse with lower and upper bounds inherited from ancestors: each node must satisfy lo < key < hi, the left child gets (lo, key) and the right child gets (key, hi). Alternatively do an inorder traversal and check that values are strictly increasing. O(n).

</QA>

<QA q="How do you delete a node with two children from a BST?">

Replace its key with its inorder successor (the minimum of its right subtree) or predecessor, then delete that successor node from the right subtree, which has at most one child. The BST property is preserved.

</QA>

<CheatSheet>

| Op | Rule | Time |
| --- | --- | --- |
| Search/insert | smaller → left, bigger → right | O(h) |
| Delete 2 children | copy inorder successor, delete it | O(h) |
| Min / max | leftmost / rightmost | O(h) |
| Sorted | inorder | O(n) |
| Validate | bounds (lo, hi) | O(n) |
| k-th smallest | inorder with counter | O(h + k) |
| Height h | balanced vs chain | O(log n) · O(n) |

</CheatSheet>
