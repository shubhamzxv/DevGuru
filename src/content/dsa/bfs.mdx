<Analogy>

A **ripple in a pond**. Drop a stone and the wave reaches everything 1 metre away first, then 2 metres, then 3. BFS spreads from the start the same way: all friends first, then friends of friends, then their friends. So the first time it reaches a node is along the **shortest** route.

</Analogy>

## Simple explanation

```python
from collections import deque

def bfs(graph, start):
    seen = {start}
    q = deque([start])
    while q:
        node = q.popleft()          # oldest first = closest first
        for nxt in graph[node]:
            if nxt not in seen:
                seen.add(nxt)       # mark when enqueued (not when popped)
                q.append(nxt)
```

| Property | BFS |
| --- | --- |
| Data structure | **queue** (`deque`) |
| Order | by distance from the start (levels) |
| Shortest path | **yes**, in edges (unweighted graphs) |
| Time / space | O(V + E) / O(V) |

**Variants**

| Variant | Use |
| --- | --- |
| Track `dist[node]` or process level by level | shortest number of steps |
| Track `parent[node]` | rebuild the actual path |
| **Grid BFS** | shortest path in a maze, knight moves |
| **Multi-source BFS** (start with many nodes in the queue) | rotting oranges, distance to nearest exit, fire spreading |
| BFS over states | word ladder, open the lock, sliding puzzles (state = node) |
| 0-1 BFS (deque, weights 0/1) | special weighted cases |

BFS vs DFS: BFS finds the **closest** answer first and uses memory for a whole level; DFS goes deep, uses less memory on wide graphs, and suits "explore everything", cycles and backtracking.

## Code example

```python
from collections import deque

graph = {"A": ["B", "C"], "B": ["D", "E"], "C": ["F", "G"], "D": [], "E": ["H"], "F": ["H"], "G": [], "H": []}

def shortest_path(graph, start, goal):
    parent = {start: None}
    q = deque([start])
    while q:
        node = q.popleft()
        if node == goal:
            path = []
            while node:
                path.append(node)
                node = parent[node]
            return path[::-1]
        for nxt in graph[node]:
            if nxt not in parent:
                parent[nxt] = node
                q.append(nxt)
    return None

print("A → H:", shortest_path(graph, "A", "H"))

def maze_steps(maze, start, end):
    rows, cols = len(maze), len(maze[0])
    q = deque([(start, 0)])
    seen = {start}
    while q:
        (r, c), d = q.popleft()
        if (r, c) == end:
            return d
        for dr, dc in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and maze[nr][nc] == "." and (nr, nc) not in seen:
                seen.add((nr, nc))
                q.append(((nr, nc), d + 1))
    return -1

maze = ["..#....",
        ".##.##.",
        "......#",
        "#.##...",
        "....#.."]
print("maze steps:", maze_steps(maze, (0, 0), (4, 6)))

def rotting_oranges(grid):
    """Multi-source BFS: minutes until every orange rots (2 = rotten, 1 = fresh)."""
    rows, cols = len(grid), len(grid[0])
    q = deque((r, c) for r in range(rows) for c in range(cols) if grid[r][c] == 2)
    fresh = sum(row.count(1) for row in grid)
    minutes = 0
    while q and fresh:
        for _ in range(len(q)):                  # one minute = one level
            r, c = q.popleft()
            for dr, dc in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    q.append((nr, nc))
        minutes += 1
    return minutes if fresh == 0 else -1

print("minutes:", rotting_oranges([[2, 1, 1], [1, 1, 0], [0, 1, 1]]))
```

from collections import deque

def word_ladder(begin, end, words):
    """Fewest one-letter changes from begin to end (each step must be a word in the list)."""
    words = set(words)
    q, seen = deque([(begin, 1)]), {begin}
    while q:
        word, steps = q.popleft()
        if word == end:
            return steps
        for i in range(len(word)):
            for ch in "abcdefghijklmnopqrstuvwxyz":
                nxt = word[:i] + ch + word[i + 1:]
                if nxt in words and nxt not in seen:
                    seen.add(nxt)
                    q.append((nxt, steps + 1))
    return 0

print(word_ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"]))   # hit→hot→dot→dog→cog

<InterviewQA>

<QA q="Why does BFS find the shortest path in an unweighted graph?">

It visits nodes in order of their distance from the source: all nodes at distance 1 are dequeued before any at distance 2, and so on. So the first time a node is reached, it is via a path with the fewest edges.

</QA>

<QA q="How do you get the path, not just the distance, from BFS?">

Record each node's parent when it is first discovered; after reaching the goal, follow parent links back to the start and reverse the list.

</QA>

<QA q="What is multi-source BFS?">

BFS that starts with several source nodes in the queue at distance 0, computing for every node the distance to the nearest source in one O(V + E) pass. Used for rotting oranges, distance to the nearest gate, or spreading processes.

</QA>

<CheatSheet>

| Need | Code |
| --- | --- |
| Queue | `q = deque([start])` · `popleft()` |
| Visited | `seen.add` when enqueuing |
| Distance | `(node, d)` in queue, or level loop `for _ in range(len(q))` |
| Path | `parent[n]` then walk back |
| Grid | 4 directions + bounds check |
| Many starts | multi-source: all in queue first |
| Cost | O(V + E) |
| Weighted | use Dijkstra instead |

</CheatSheet>
