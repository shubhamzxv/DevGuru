<Analogy>

A **stack of plates** in a canteen. You put a clean plate on **top** (push) and take a plate from the **top** (pop). The last plate placed is the first one used: **Last In, First Out**.

</Analogy>

## Simple explanation

| Operation | Python list | Time |
| --- | --- | --- |
| push | `stack.append(x)` | O(1) |
| pop | `stack.pop()` | O(1) |
| peek (top) | `stack[-1]` | O(1) |
| empty? | `not stack` | O(1) |

Always use the **end** of the list as the top (`pop(0)` would be O(n)).

**Where stacks appear**

| Use | Why a stack |
| --- | --- |
| Balanced brackets `({[]})` | the most recent opener must close first |
| Undo / back button | the last action is undone first |
| Function calls | the call stack: the latest call returns first |
| DFS without recursion | push neighbours, pop the latest |
| Evaluate expressions (postfix, calculators) | operands wait for their operator |
| **Monotonic stack** | next greater / smaller element, daily temperatures, largest rectangle |

**Monotonic stack**: keep the stack sorted (e.g. decreasing). When a new value is bigger than the top, the top has found its "next greater element" — pop it and record the answer. Every index is pushed and popped once → **O(n)** instead of O(n²).

## Code example

```python
def is_balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for c in s:
        if c in "([{":
            stack.append(c)
        elif c in pairs:
            if not stack or stack.pop() != pairs[c]:
                return False
    return not stack                       # leftovers = unclosed openers

def eval_postfix(tokens):
    stack = []
    for t in tokens:
        if t in "+-*/":
            b, a = stack.pop(), stack.pop()   # order matters for - and /
            stack.append({"+": a + b, "-": a - b, "*": a * b, "/": int(a / b)}[t])
        else:
            stack.append(int(t))
    return stack[0]

def daily_temperatures(temps):
    """Days to wait for a warmer day (monotonic decreasing stack of indexes)."""
    answer = [0] * len(temps)
    stack = []
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            answer[j] = i - j
        stack.append(i)
    return answer

print(is_balanced("{[()()]}"), is_balanced("([)]"), is_balanced("(("))
print(eval_postfix(["2", "1", "+", "3", "*"]))          # (2 + 1) * 3
print(daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73]))
```

```output
[1, 1, 4, 2, 1, 1, 0, 0]
```

```python
class MinStack:
    """push, pop, top and get_min all in O(1)."""
    def __init__(self):
        self.items = []                 # pairs: (value, min so far)

    def push(self, x):
        current_min = min(x, self.items[-1][1]) if self.items else x
        self.items.append((x, current_min))

    def pop(self):
        return self.items.pop()[0]

    def get_min(self):
        return self.items[-1][1]

s = MinStack()
for x in [5, 3, 7, 2]:
    s.push(x)
print(s.get_min())      # 2
s.pop()
print(s.get_min())      # 3

# Try it: push 1, then pop twice, printing get_min() each time.
```

<InterviewQA>

<QA q="How do you check if brackets are balanced?">

Scan the string pushing opening brackets onto a stack; for a closing bracket, the stack must be non-empty and its top must be the matching opener, which is popped. At the end the stack must be empty. O(n) time, O(n) space.

</QA>

<QA q="What is a monotonic stack?">

A stack kept in increasing or decreasing order. When a new element breaks the order, elements are popped, and each popped element has just found its next greater (or smaller) element. Since each index is pushed and popped once, problems like next greater element, daily temperatures and largest rectangle in a histogram run in O(n).

</QA>

<QA q="Design a stack that returns the minimum in O(1).">

Store, with each pushed value, the minimum of the stack at that point (or keep a second stack of minimums). Push records min(new value, previous minimum); pop removes both; get_min reads the top's stored minimum.

</QA>

<CheatSheet>

| Need | Code |
| --- | --- |
| push / pop / peek | `append(x)` / `pop()` / `[-1]` |
| empty | `not stack` |
| brackets | push openers · match closers · empty at end |
| postfix | pop b, then a · push result |
| next greater | `while stack and a[stack[-1]] < x: pop` |
| min stack | store (value, min so far) |
| DFS | push start · pop · push neighbours |
