<Analogy>

An endless **locker room**: each bucket is a locker room with a unique name, each object is a parcel with a label (the key, like `products/7/headphones.jpg`). AWS copies every parcel to several buildings so it is practically never lost. Lockers are locked by default; a **presigned URL** is a one-time token you give someone to pick up one parcel within 5 minutes.

</Analogy>

## Simple explanation

| Concept | Meaning |
| --- | --- |
| **Bucket** | container with a **globally unique** name, created in a Region |
| **Object** | the data (up to 5 TB) + metadata (content type, tags) |
| **Key** | the full name: `products/7/headphones.jpg` (the "folders" are just prefixes) |
| **Durability / availability** | 99.999999999% (11 nines) durability; ~99.99% availability (Standard) |

**Storage classes**

| Class | For | Note |
| --- | --- | --- |
| S3 Standard | frequently used data | default |
| S3 Intelligent-Tiering | unknown access patterns | moves objects automatically |
| Standard-IA / One Zone-IA | infrequent access | cheaper storage, retrieval fee |
| Glacier Instant / Flexible / Deep Archive | archives | cheapest, minutes to hours to restore |

**Everyday operations**

```bash
aws s3 mb s3://shop-media-shubham --region ap-south-1
aws s3 cp headphones.jpg s3://shop-media-shubham/products/7/
aws s3 ls s3://shop-media-shubham/products/ --recursive
aws s3 sync ./build s3://shop-frontend --delete          # deploy a static site
aws s3 presign s3://shop-media-shubham/invoices/2026/11/order-4.pdf --expires-in 300
```

**Typical uses**: user uploads, product images, static websites (with CloudFront), backups, logs, data lake (Athena queries), Docker layers, Terraform state.

**Security basics**: buckets are **private by default** and **Block Public Access** is on. Give access with IAM policies (apps via roles), bucket policies, and **presigned URLs** for temporary download/upload. Encryption at rest is on by default (SSE-S3); use SSE-KMS for key control. See the next topic for permissions, versioning and lifecycle.

Upload large files with **multipart upload** (the SDK/CLI does it automatically); let browsers upload directly with a **presigned POST/PUT** so files do not pass through your server. **Event notifications** can trigger Lambda, SQS or EventBridge on upload.

## Code example

```python
import boto3

s3 = boto3.client("s3", region_name="ap-south-1")
s3.create_bucket(Bucket="shop-media-shubham", CreateBucketConfiguration={"LocationConstraint": "ap-south-1"})
s3.put_object(Bucket="shop-media-shubham", Key="products/7/headphones.jpg", Body=jpeg_bytes, ContentType="image/jpeg")
s3.put_object(Bucket="shop-media-shubham", Key="invoices/2026/11/order-4.pdf", Body=pdf_bytes)

for o in s3.list_objects_v2(Bucket="shop-media-shubham")["Contents"]:
    print(" ", o["Key"], o["Size"], "bytes", o["StorageClass"])
print("prefix products/:", [o["Key"] for o in s3.list_objects_v2(Bucket="shop-media-shubham", Prefix="products/")["Contents"]])

url = s3.generate_presigned_url("get_object", ExpiresIn=300,
                                Params={"Bucket": "shop-media-shubham", "Key": "invoices/2026/11/order-4.pdf"})
print("presigned:", url.split("?")[0], "?X-Amz-Algorithm=...&X-Amz-Expires=300&X-Amz-Signature=...")

try:
    s3.get_object(Bucket="shop-media-shubham", Key="nope.jpg")
except s3.exceptions.NoSuchKey as e:
    print("missing key:", e.response["Error"]["Code"])
```

```output
  invoices/2026/11/order-4.pdf 9 bytes STANDARD
  products/7/headphones.jpg 12 bytes STANDARD
prefix products/: ['products/7/headphones.jpg']
presigned: https://shop-media-shubham.s3.amazonaws.com/invoices/2026/11/order-4.pdf ?X-Amz-Algorithm=...&X-Amz-Expires=300&X-Amz-Signature=...
missing key: NoSuchKey
```

<Mistakes>

<Mistake title="Making the bucket public to show images">

<Wrong>

```text
Turn off Block Public Access and add "Principal": "*" to the bucket policy — then invoices and ID scans are public too.
```

</Wrong>

<Right>

```text
Keep the bucket private; serve public images through CloudFront with Origin Access Control, and private files with presigned URLs.
```

</Right>

</Mistake>

<Mistake title="Uploading big files through the API server">

<Wrong>

```text
Browser → API server (holds 2 GB in memory / times out) → S3
```

</Wrong>

<Right>

```text
API returns a presigned PUT/POST URL → browser uploads directly to S3 (multipart for big files).
```

</Right>

</Mistake>

<QA q="What is Amazon S3?">

An object storage service for any amount of data, organised in buckets with globally unique names, where each object is addressed by a key and stored redundantly across multiple AZs for 11 nines of durability. It is accessed via HTTPS APIs, private by default, and offers storage classes, versioning, lifecycle rules, encryption, event notifications and static website hosting.

</QA>

<QA q="How do you let users download private files securely?">

Generate presigned URLs on the server (with an IAM role that may read the object) after checking the user's permission; the URL grants time-limited access to one object. For public assets use CloudFront with Origin Access Control so the bucket itself stays private; CloudFront signed URLs or cookies work for private content at scale.

</QA>

<QA q="Is S3 a file system?">

No. It is a flat key-value object store: "folders" are just key prefixes, objects are replaced as a whole (no in-place edits or appends), and it is accessed over an API rather than mounted like a disk. Use EBS for block storage or EFS for a shared file system; Mountpoint for S3 offers file-like read access.

</QA>

<CheatSheet>

| Task | Command / API |
| --- | --- |
| Create | `aws s3 mb s3://bucket --region ap-south-1` |
| Upload / download | `aws s3 cp f s3://bucket/key` · `s3.put_object` / `get_object` |
| List | `aws s3 ls s3://bucket/prefix/ --recursive` · `list_objects_v2(Prefix=)` |
| Sync | `aws s3 sync ./build s3://site --delete` |
| Temporary access | `aws s3 presign` · `generate_presigned_url` |
| Classes | Standard · Intelligent-Tiering · IA · Glacier (Instant/Flexible/Deep Archive) |
| Safety | private by default · Block Public Access · SSE encryption |
| Events | ObjectCreated → Lambda / SQS / EventBridge |

</CheatSheet>
