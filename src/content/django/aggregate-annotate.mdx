title: aggregate and annotate
summary: aggregate() computes summary values over a whole QuerySet and returns a dict (total, average, max), while annotate() adds a computed value to each row (orders per customer, total per order); values() before annotate() groups like SQL GROUP BY.
updated: "2026-11-15"

<Analogy>

A shop's day-end report. **aggregate** is the single line at the bottom: "Total sales: ₹4,143. Average bill: ₹1,381." **annotate** is the extra column you add to every line: "Asha: 2 orders, ₹848 paid; Ravi: 1 order, ₹1,796 paid".

</Analogy>

## Simple explanation

```python
from django.db.models import Avg, Count, F, Max, Min, Q, Sum
```

**aggregate**: one result for the whole QuerySet (a dict):

```python
Product.objects.aggregate(total=Count("id"), avg=Avg("price"), max=Max("price"), min=Min("price"))
Product.objects.aggregate(stock_value=Sum(F("price") * F("stock")))
```

**annotate**: a value per row (SQL `GROUP BY` behind the scenes):

```python
Category.objects.annotate(n=Count("products"), avg=Avg("products__price"))
Order.objects.annotate(total=Sum(F("items__price") * F("items__quantity")))
User.objects.annotate(
    n_orders=Count("orders", distinct=True),
    spent=Sum(F("orders__items__price") * F("orders__items__quantity"), filter=Q(orders__status="paid")),
)
```

Then you can **filter and sort** on the annotation: `.filter(n__gte=2)` (SQL `HAVING`), `.order_by("-spent")`.

**Group by a field**: `values()` first, then `annotate()`:

```python
Order.objects.values("status").annotate(n=Count("id"))
# [{'status': 'paid', 'n': 2}, {'status': 'pending', 'n': 1}]
```

Gotchas:

- Two `Count`/`Sum` across **different** relations in one query multiply rows; use `distinct=True` for counts or subqueries (`Subquery`, `OuterRef`)
- `Sum` of nothing is `None`: wrap with `Coalesce(Sum(...), 0)`
- Default `Meta.ordering` can sneak into `GROUP BY`; add `.order_by()` to clear it when grouping with `values()`

Other useful expressions: `Case`/`When` (conditional values), `ExpressionWrapper`, `functions.TruncMonth("created_at")` for monthly reports, `Window` functions for rankings.

## Code example

```python
>>> Product.objects.aggregate(total=Count("id"), avg=Avg("price"), max=Max("price"), min=Min("price"))
>>> Product.objects.aggregate(stock_value=Sum(F("price") * F("stock")))
>>> for c in Category.objects.annotate(n=Count("products"), avg=Avg("products__price")).order_by("-n"):
...     print(c.name, c.n, round(c.avg, 2))
>>> for o in Order.objects.annotate(total=Sum(F("items__price") * F("items__quantity"))):
...     print(o.id, o.customer.username, o.status, o.total)
>>> for u in User.objects.annotate(n_orders=Count("orders", distinct=True),
...         spent=Sum(F("orders__items__price") * F("orders__items__quantity"), filter=Q(orders__status="paid"))).order_by("-spent"):
...     print(u.username, u.n_orders, u.spent)
>>> Order.objects.values("status").annotate(n=Count("id")).order_by("status")
>>> Category.objects.annotate(n=Count("products")).filter(n__gte=2).values_list("name", flat=True)
```

<InterviewQA>

<QA q="What is the difference between aggregate and annotate?">

`aggregate()` evaluates immediately and returns a dictionary with values computed over the whole QuerySet (like a SELECT with aggregate functions and no GROUP BY). `annotate()` returns a QuerySet where each object gets an extra computed attribute, computed per row or per group (GROUP BY), which can then be filtered, ordered or aggregated again.

</QA>

<QA q="How do you get the number of orders per customer?">

`User.objects.annotate(n_orders=Count("orders")).order_by("-n_orders")`, or grouped values: `Order.objects.values("customer__username").annotate(n=Count("id"))`. Use `filter=Q(...)` inside Count for conditional counts such as paid orders only.

</QA>

<QA q="How do you write a monthly sales report with the ORM?">

`Order.objects.filter(status="paid").annotate(month=TruncMonth("created_at")).values("month").annotate(revenue=Sum(F("items__price") * F("items__quantity")), orders=Count("id", distinct=True)).order_by("month")`.

</QA>

<CheatSheet>

| Need | Code |
| --- | --- |
| Whole table summary | `.aggregate(avg=Avg("price"), n=Count("id"))` |
| Per row | `.annotate(n=Count("products"))` |
| Per group | `.values("status").annotate(n=Count("id"))` |
| Conditional | `Count("orders", filter=Q(orders__status="paid"))` |
| Expressions | `Sum(F("price") * F("quantity"))` |
| None → 0 | `Coalesce(Sum(...), 0)` |
| HAVING | `.annotate(n=...).filter(n__gte=2)` |
| By month | `TruncMonth("created_at")` |

</CheatSheet>
