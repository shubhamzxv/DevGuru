<Analogy>

A building's **directory board** in the lobby: "Accounts → 3rd floor, Room 301". You do not memorise room numbers; you look up the **name**. If Accounts moves to another room, only the board changes. Named URLs are that board.

</Analogy>

## Simple explanation

```python
# store/urls.py
from django.urls import path
from . import views

app_name = "store"                     # namespace

urlpatterns = [
    path("", views.product_list, name="product-list"),
    path("<int:pk>/", views.product_detail, name="product-detail"),
    path("new/", views.product_create, name="product-create"),
    path("category/<slug:slug>/", views.by_category, name="by-category"),
]
```

```python
# config/urls.py
from django.urls import include, path

urlpatterns = [
    path("admin/", admin.site.urls),
    path("products/", include("store.urls")),      # /products/, /products/7/, ...
    path("api/", include("store.api_urls")),
]
```

**Path converters**

| Converter | Matches | Gives |
| --- | --- | --- |
| `<int:pk>` | `7` | `int` |
| `<str:name>` | any text without `/` (default) | `str` |
| `<slug:slug>` | `clean-code` | `str` |
| `<uuid:id>` | a UUID | `UUID` |
| `<path:file>` | text with `/` | `str` |

The captured values arrive as keyword arguments: `def product_detail(request, pk)`. `re_path()` accepts regular expressions when needed.

**Build URLs by name** (never hard-code paths):

```python
from django.urls import reverse
reverse("store:product-detail", args=[7])        # '/products/7/'
redirect("store:product-detail", pk=7)           # in views
```

```html
<a href="{% url 'store:product-detail' product.pk %}">{{ product.name }}</a>
```

Also: `get_absolute_url()` on models, `APPEND_SLASH` (redirects `/products` → `/products/`), patterns are matched **in order**, the query string (`?q=`) is not part of the path (read it with `request.GET`), and custom error views with `handler404`/`handler500` in the root URLconf.

## Code example

```python
>>> from django.urls import reverse, resolve
>>> reverse("store:product-detail", args=[7])
>>> reverse("store:product-list")
>>> resolve("/products/7/").func.__name__, resolve("/products/7/").kwargs
```

```output
'/products/7/'
'/products/'
('product_detail', {'pk': 7})
```

```output
GET /products/7/     → product_detail(request, pk=7)
GET /products/abc/   → 404 (int converter does not match)
GET /products        → 301 → /products/  (APPEND_SLASH)
```

```python
# config/urls.py — try changing the order or the converters and visit the URLs
from django.contrib import admin
from django.http import HttpResponse
from django.urls import include, path

def hello(request, name):
    return HttpResponse(f"Hello, {name}!")

def order_detail(request, order_id):
    return HttpResponse(f"Order #{order_id} ({type(order_id).__name__})")

urlpatterns = [
    path("admin/", admin.site.urls),
    path("hello/<str:name>/", hello, name="hello"),             # /hello/asha/
    path("orders/<int:order_id>/", order_detail, name="order"),  # /orders/42/  vs  /orders/abc/
]
```

<InterviewQA>

<QA q="How does URL routing work in Django?">

ROOT_URLCONF points to a module with `urlpatterns`. Django tries each `path()` or `re_path()` in order; `include()` delegates the rest of the path to another URLconf. The first match calls its view with the captured, converted parameters as keyword arguments; no match returns 404.

</QA>

<QA q="What is reverse() and why use URL names?">

`reverse("namespace:name", args=...)` builds a URL from its name, and the `{% url %}` tag does the same in templates. Naming routes (with app namespaces) avoids hard-coded paths, so URLs can change in one place without breaking links, redirects or tests.

</QA>

<CheatSheet>

| Need | Code |
| --- | --- |
| Route | `path("<int:pk>/", views.detail, name="product-detail")` |
| Namespace | `app_name = "store"` |
| Nest | `path("products/", include("store.urls"))` |
| Converters | `int` · `str` · `slug` · `uuid` · `path` |
| Python URL | `reverse("store:product-detail", args=[7])` |
| Template URL | `{% url 'store:product-detail' product.pk %}` |
| Redirect | `redirect("store:product-detail", pk=7)` |
| Query string | `request.GET.get("q")` |
